## Ejercicio 1: ¿Cuál es la diferencia entre Num e Int?
```text
La diferencia entre Num e Int radica en que Num es una clase de tipos.
Donde sus miembros tienenla propiedad de comportarse como cualquier tipo
de números, incluso los enteros. Por su parte Int es un tipo de dato
concreto por eso solo trabaja con números enteros. Como ejemplo al
ingresar un número en Haskell no se le asigna un tipo directamente si no
que lo trabaja dentro de Num que puede ser cualquier tipo de número como
Float, Double, Integer o Int.
```
