Objetivo de la Práctica: Empezar a entender de mejor manera como funciona Haskell realizando nuestras propias funciones, usando las operaciones básicas como: suma, resta, multiplicación y división; y funciones como, mod, sqrt y la condicional If-Then-Else. Identificar que tipo de dato vamos a ingresar y cual vamos a recibir para que la función se ejecute bien y cumpla su objetivo.

Tiempo requerido: Aproximadamente unos 4 días, entre sesiones de 2 a 3 horas.
