Objetivo de la practica:
El objetivo de esta practica es aprender como instalar una versión de Haskell en nuestro respectivo sistema operativo. Así como el seguir familiarizandonos con la plataforma de Github para que cada vez seamos mucho más rapidos a la hora de trabajar. Tambien el conocer un poco más acerca de Haskell al realizar un pequeña investigación para contestar algunas preguntas.

Tiempo requerido en realizar la práctica completa:
Tarde unas 2 horas en buscar y comparar información para contestar las preguntas.

Comentarios y problemas a los que te enfrentaste en la instalación con su respectiva solución:
No tuve mayores complicaciones para instalar Haskell, con el comando y siguindo las indicaciones de la practica solo tuve que esperar a que todo se descargara para configurar todo en predeteminado. Y comprobar que todo se instalo correctamente con el comando "ghcup --version" para ver que versión de haskell tengo.
